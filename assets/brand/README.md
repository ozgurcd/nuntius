# nuntius logo — "Relay"

One sender (gold) dispatching a message (gold chevron) along three paths to three lanes (ink) — *nuntius* is Latin for messenger.
Original work by the Identuum judge session, 2026-10-10, made only from lines and circles (no fonts, clip art or third-party marks).
Dedicated to the public domain: CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/).

Colours: ink #1F3A5F, gold #C8962E; dark mode ink #D9E4F2, gold #E0B04E.

Files

- nuntius-logo-mono.svg — one colour (currentColor) for docs and CLI pages.
- nuntius-app-icon.svg + png/nuntius-app-icon-{16..1024}.png — rounded tile for app/cask icons.
